## Adapter Pattern

### Definition

Allows incompatible systems to work together by converting one interface into another.

### Real-World Analogy

A travel adapter allows your charger to work in another country even though the plug types are different.

### When to Use

* Third-party integrations
* Legacy system integration
* API migrations

### Benefits

* Promotes reuse
* Simplifies integration
* Reduces changes to existing code

### Production Example

Integrating an external vendor API into an internal application.
