## Decorator Pattern

### Definition

Adds additional behavior to an object without modifying its original implementation.

### Real-World Analogy

A pizza remains a pizza whether you add cheese, olives, or mushrooms. The base stays unchanged while functionality is enhanced.

### When to Use

* Logging
* Performance monitoring
* Authentication
* Retry mechanisms

### Benefits

* Extends behavior dynamically
* Avoids modifying existing code
* Supports Open/Closed Principle

### Production Example

Adding execution-time logging to service methods.
