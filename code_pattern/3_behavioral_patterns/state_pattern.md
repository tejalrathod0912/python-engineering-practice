## State Pattern

### Definition

Allows an object to change its behavior when its internal state changes.

### Real-World Analogy

A traffic light behaves differently when it is green, yellow, or red.

### When to Use

* Workflow systems
* Order processing
* Approval systems

### Benefits

* Removes complex conditional logic
* Improves maintainability
* Models real-world behavior clearly

### Production Example

An order moving through Pending, Approved, Shipped, and Delivered states.
