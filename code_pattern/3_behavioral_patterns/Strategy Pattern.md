## Strategy Pattern

### Definition

Encapsulates different algorithms and allows them to be selected at runtime.

### Real-World Analogy

A navigation app lets you choose driving, walking, or cycling routes. The destination remains the same, but the strategy changes.

### When to Use

* Multiple validation rules
* Different pricing models
* Multiple processing algorithms

### Benefits

* Eliminates large if-else blocks
* Improves extensibility
* Supports Open/Closed Principle

### Production Example

Supporting different file-processing strategies for CSV, JSON, and XML files.
